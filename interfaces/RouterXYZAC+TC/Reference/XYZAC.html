RouterXYZAC+TC — Current machine contract

Updated 10 November 2026. Operator manual contents

Five coordinates

X/Y/Z use millimeters; A/C use unwrapped degrees. The Machine and Work panels show all five coordinates. Readiness lamps show X, Y, Z, A and C. Readiness is separate from Homed. Gantry companions are motors, not extra job coordinates.

Jog and startup

Every launch opens the direction-button page with Step Jog off. The arrows switch between direction buttons and five-axis parameters. Page and mode are not saved; speed, step and destination values are saved. XYZ speed/step uses mm/s and mm; A/C uses degrees/s and degrees. Continuous Jog stops on release. Step Jog moves one step. Goto uses the axis machine-coordinate destination and requires the machine to be homed.

Home and training

The generated sequence is Z, then A/C, then X/Y; individual Home A and Home C are available as commands. Hard Simulation creates nearby virtual sensors at each Home activation: 5 mm from the starting linear position and 2 degrees from the starting rotary position, in the configured direction. The normal PLC still searches, stops, releases the sensor and assigns Home. Completion, cancellation and reconnect rearm the model. Physical settings are unchanged. Very low configured velocity or large displacement can still take time.

Programs and 3D view

The dedicated RouterXYZACTC interpreter retains all five coordinates through load, selected start, restart and M6 continuation. It rejects B and RTCP commands. Inch mode scales XYZ only. C370 stays 370 degrees. Mixed G94 motion uses linear feed; pure rotary motion uses degrees/minute. The preview path is an XYZ projection. The live marker rotates with A/C using CParent ordering (C carries A); XYZ is not compensated. This is not collision detection or a model of the physical tool tip.

Tools, references and return moves

Each tool station includes XYZ position and A/C angles. Approach lifts Z, moves/reorients at safe Z, then descends. Pickup/placement vectors remain XYZ and hold station angles. Manual exchange returns the captured five-axis start; program exchange keeps the five-axis continuation. Six G54–G59 references and G28/G30/park destinations include A/C. Main-window reference editors remain XYZ; edit angular references in Configuration. Probe measurement requires A=C=0 and remains Z-only.

Limits and persistence

Default travel is A −180..180 and C −360..360 degrees. Configure scales, directions, speeds, home settings and clearance for the actual mechanism. LinkManager owns parameter commit and save; Enter/validation accepts, Escape restores the accepted value. Existing engineered PLC programs are preserved. Short simulated Home does not demonstrate real sensor placement, clearance or hardware timing.

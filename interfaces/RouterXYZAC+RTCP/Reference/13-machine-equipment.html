13.1 Identify other options and obtain their operating instructions

Different routers can share the same application while having different accessories. A machine may have lubrication equipment, a coolant device, an external operator panel or additional spindle equipment. Some names are provided in the standard signal list so that a machine builder can configure an installation. A name in that list is not the same as a finished, commissioned feature.

For an operator, the useful question is: what is installed on this machine, what is its approved control, and how is completion confirmed? Do not infer an operating procedure from a signal name. In particular, an input called RunSwitch does not by itself establish what a physical button will start, whether it must be held or what checks will apply.

Table 13-1. Supplied equipment names and the limits of this chapter
Equipment or indicationWhat the supplied application establishesWhat must come from the delivered machine documentation
Coolant and LubricantOutput names are provided; this does not establish an automatic operating cycle.The installed system, approved use, operating control and checks. Do not assume a program command operates it solely because its name exists.
RunSwitch, PauseSwitch and StopSwitchExternal input names are available in the signal list.The actual physical-button functions and their relationship to the screen controls.
BrakeThe supplied Z-brake request depends on the configured axis, mapped drive, servo-on command, drive readiness and absence of drive or coupling faults.The actual brake arrangement, holding capability, access and service procedure. It is not a manual lifting or lowering control.
PressureSensorIf physically assigned, its logical state participates in spindle readiness.The required physical pressure, gauge reading and supply checks. A logical HIGH is not a numerical pressure measurement.

Use a machine-specific option record

Before independent operation, obtain a short record for every accessory you are expected to use. It should identify the physical device, its control and its normal indications. If a particular option is absent, mark it “Not fitted”. If it is fitted but not commissioned, mark that explicitly rather than leaving a blank that another operator could interpret as permission to use it.

Table 13-2. Information to add to the installation's option record
Record itemInformation to enter for each installed option

Normal sequenceWhat moves first, what follows and what indicates completion.

When the delivered machine differs

The machine's saved control programs can contain installation-specific behavior. That is why this chapter identifies the supplied behavior rather than promising that every machine has an identical sequence. If an option has been added or its behavior changed, the corresponding operator instructions must describe the delivered sequence. Operators should not have to read control-program text to discover which button is safe to press.

Do not use an input/output editor as a substitute control panel for undocumented equipment. A direct output change may omit the sequencing, movement checks or confirmations that an approved operation requires. Report the missing procedure and obtain a demonstration and written instructions from the responsible person.
